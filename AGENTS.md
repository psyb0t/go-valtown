# go-valtown

Unofficial Go client for the Val Town API, generated from Val Town's OpenAPI document. If you only want to use the client from an agent, read [.agents/skills/go-valtown/SKILL.md](.agents/skills/go-valtown/SKILL.md) instead; this file is about changing the code.

## Architecture

One generated package, `valtown`, in the repository root, from `https://api.val.town/openapi.json`.

Data flow, declared in `gen.go`: `scripts/fetch-spec.sh` (download into the gitignored `api/openapi.json`) → `scripts/fix-spec.sh` with `scripts/fix-valtown-spec.jq` (`api/openapi.fixed.json`) → `go tool oapi-codegen` with `config.yaml` → `client.gen.go`.

## Stack

- Go 1.26.10. oapi-codegen v2 as a `go.mod` tool; `github.com/oapi-codegen/runtime` at runtime.
- jq for the spec patch. No hand-written library code.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`, `client_test.go`, `example_test.go`: the `valtown` package.
- `scripts/`: spec fetch, the spec patch filter, lint and security scan scripts.
- `api/`: the downloaded spec, gitignored, never committed.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make generate  # download the spec, patch it, regenerate
make dep       # go mod tidy + go mod vendor
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The spec writes many string enums without `type`. Unpatched, oapi-codegen makes those fields `interface{}` with no constants. `fix-valtown-spec.jq` adds `type: string`; if an upstream change drops the patch, `TestValsList2` stops compiling because it uses `ValsList2ParamsPrivacyPublic` and `ValPrivacyPublic`.
- Several request bodies are defined types over generated structs (`SqliteExecuteJSONRequestBody`, `EmailsSendJSONRequestBody` and others). That is fine for plain structs. If upstream turns one into a `oneOf`, the defined type drops the union's `MarshalJSON` and the client sends `{}`; move the schema into `components` in the jq filter so the body type becomes an alias.
- semgrep's `unsafe-deserialization-interface` rule is excluded in `scripts/sec.sh`. oapi-codegen decodes untyped response schemas into `interface{}`, which the spec leaves no way around.
- The CI pipeline skips the generate drift check, because the spec changes upstream without notice. Regenerate locally and commit the result.
- `.github/workflows/regen.yml` regenerates the client every day and releases the result. When the checks fail, Claude edits the repository to fix them, but a fix may not touch the paths listed under `fix_protected_paths` in that workflow: the workflows, the Makefile, `AGENTS.md`, `.agents/rules/`, the lint, security and spec download scripts and their configs. A problem that needs a change there fails the run and needs a manual fix.
